# Suraksha Alert

Suraksha Alert is a frontend-only women’s safety prototype.

## Included

- Hold-to-activate demo SOS alert
- Browser geolocation request
- Voice phrase detection using Web Speech API
- Emergency contact management
- Complaint filing with local demo reference number
- Complaint history
- Aadhaar verification placeholder
- Responsive accessible interface
- Local browser storage

## Important safety notice

This project is not connected to police, emergency services, SMS providers, email providers, or real identity-verification services.

It must not be used as a real emergency service until it has undergone:

- Legal and privacy review
- Security testing
- Accessibility testing
- Backend implementation
- Authorized emergency-service integration
- Identity-verification compliance review
- Evidence-storage review
- Reliability and failure testing

Do not add real Aadhaar numbers, OTPs, biometric information, private evidence, or real emergency contacts to this demo.
